# Передача следующему ИИ-исполнителю

Прочитай README, AGENTS, утверждённые решения и соответствующий GDD. Запусти `python tools/work_plan.py validate`, затем `python tools/work_plan.py next`. Проверь существующие PR, не дублируй незавершённую задачу.

После работы передай: ID задачи, ветку, PR, SHA, тесты, ошибки и следующий шаг. Статус `done` только после подтверждённого merge SHA в main. Не трогай VPS без разрешения.
