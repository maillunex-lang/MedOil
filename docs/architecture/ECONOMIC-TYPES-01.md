# ECONOMIC-TYPES-01. Единые экономические типы

Согласовано с D-104, TECH-01 и GDD 07. Машиночитаемые схемы: `contracts/economy/`.

## Скалярные величины

| `kind` | Единица | Знак | Диапазон (включительно) |
|--------|---------|------|-------------------------|
| `money_kopeks` | копейка | знаковое | −9_223_372_036_854_775_808 … 9_223_372_036_854_775_807 |
| `mass_grams` | грамм | ≥ 0 | 0 … 9_223_372_036_854_775_807 |
| `volume_milliliters` | миллилитр | ≥ 0 | 0 … 9_223_372_036_854_775_807 |
| `energy_watt_hours` | ватт-час | ≥ 0 | 0 … 9_223_372_036_854_775_807 |
| `count_pieces` | штука | ≥ 0 | 0 … 9_223_372_036_854_775_807 |
| `server_tick` | серверный тик | ≥ 0 | 0 … 9_223_372_036_854_775_807 |
| `game_tick` | игровой тик | ≥ 0 | 0 … 9_223_372_036_854_775_807 |

Дробные типы (`float`, `double`) **запрещены** для денег, складов, энергии и счётчиков во всех JSON-контрактах.

## Ставки и доли

Проценты и коэффициенты передаются как **рациональное число** `{ "numerator": int, "denominator": int }` с `denominator ≥ 1`. Базисные пункты — через числитель/знаменатель (например 150 bp = `150/10000`).

## Обёртка `Quantity`

Универсальное поле партии или остатка:

```json
{ "kind": "mass_grams", "amount": 12500 }
```

`kind` должен быть из реестра `quantity-kinds.json`; `amount` соблюдает правила знака и диапазона для этого `kind`.
