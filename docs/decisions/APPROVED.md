# Утверждённые решения

## AUDIT-01 / AUDIT-02
- D-101: 7 реальных суток = 1 игровой год.
- Игровой календарь: 360 дней, 12 месяцев по 30 дней. 1 игровой день = 14 реальных минут.
- D-102: управляемая эмиссия государства и банков; денежные потоки учитываются двойной бухгалтерией.
- D-103: одна активная компания на аккаунт, множество предприятий и активов.
- D-104: целые копейки, граммы, миллилитры, ватт-часы, штуки, целые серверные метки; строгие округления.
- D-105: после ликвидации разрешена новая компания с защитой от злоупотреблений.

## TECH-01
- Android, landscape, fullscreen, safe area; Godot 4.x / GDScript, 3D изометрия.
- Go-модульный монолит + PostgreSQL, HTTPS JSON API v1 + WebSocket.
- Один постоянный мир; на старте Уфа, Стерлитамак, Нефтекамск с вымышленной планировкой.
- Сервер авторитетен для денег, складов, времени, собственности, логистики, контрактов.
- Transactional outbox, идемпотентность, версии контрактов, восстановление.
- Первый релиз: публичная альфа, только после отдельного разрешения.
