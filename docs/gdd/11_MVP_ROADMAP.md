# GDD 11. Широкий MVP и публичная альфа

Статус: проектные требования, согласованные с AUDIT-01/02 и TECH-01.

## Дизайн

Широкий MVP включает 3 города, 12 товаров, 5 основных предприятий, склады, жильё, транспорт, биржу, контракты, население, банки, налоги, банкротство, Android 3D и безопасность. Пять направлений: A сервер, B экономика, C Android, D 3D, E QA; интеграция I. Этапы: S0 фундамент; S1 экономика; S2 мир; S3 производство/торговля; S4 логистика/население; S5 финансы; S6 Android; S7 интеграция; S8 предрелиз; S9 публичная альфа. Обязательный сквозной сценарий: компания → ферма → пшеница → мельница → мука → пекарня → хлеб → перевозчик → магазин → покупка населением → отчёты и налоги. Нагрузка 100/300/500/1000 подключений измеряется, не гарантируется. APK публикуется только после отдельного согласования.

## Обязательные правила

- 7 реальных суток = 360 игровых дней; единый серверный календарь.
- Одна активная компания на аккаунт, много предприятий.
- Деньги и количества только в целых минимальных единицах.
- Сервер авторитетен; состояние сохраняется при выходе игрока.
- Операции, создающие деньги или товары, должны иметь проверяемое основание.
