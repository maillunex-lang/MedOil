# GDD 09. Интерфейс Android Forest Glass

Статус: проектные требования, согласованные с AUDIT-01/02 и TECH-01.

## Дизайн

Альбомная ориентация, полноэкранный адаптивный UI, safe area, поддержка разных DPI. Forest Glass: фон #101D1B, поверхности #1B302C, зелёный #62B79C, синий #6DA9BE, предупреждение #D8A45C, ошибка #DC7777, текст #F0F6F2. Боковая навигация: карта, компания, предприятия, рынок, логистика, финансы, города, уведомления, настройки. Управление картой одним пальцем, масштабирование двумя, касание объекта, долгое нажатие. Уведомления о сроках кредитов показывают игровую дату и реальный обратный отсчёт. Понятные offline, reconnect, retry и ошибки без повторного списания.

## Обязательные правила

- 7 реальных суток = 360 игровых дней; единый серверный календарь.
- Одна активная компания на аккаунт, много предприятий.
- Деньги и количества только в целых минимальных единицах.
- Сервер авторитетен; состояние сохраняется при выходе игрока.
- Операции, создающие деньги или товары, должны иметь проверяемое основание.
