# GDD 10. Сервер и сетевые контракты

Статус: проектные требования, согласованные с AUDIT-01/02 и TECH-01.

## Дизайн

Go + PostgreSQL, модульный монолит, один VPS на старте. HTTPS JSON API /api/v1 для команд/снимков; WebSocket /api/v1/ws для подписок и событий. Модули identity/company/world/construction/production/inventory/market/contracts/logistics/population/finance/banking/simulation/events/admin. Идемпотентные команды, транзакционный outbox, курсоры и повторная доставка, versioned schema, права подписок. Argon2id, refresh rotation, rate limits, аудит. Планировщик по игровым тикам, восстановление пропущенных событий. PostgreSQL backup/restore с тестами. Никакой клиентской авторитетной арифметики.

## Обязательные правила

- 7 реальных суток = 360 игровых дней; единый серверный календарь.
- Одна активная компания на аккаунт, много предприятий.
- Деньги и количества только в целых минимальных единицах.
- Сервер авторитетен; состояние сохраняется при выходе игрока.
- Операции, создающие деньги или товары, должны иметь проверяемое основание.
