# Правила ИИ-исполнителя Industrial Empire

1. Перед любым изменением: README, утверждённые решения, соответствующие GDD, TECH-01, описание задачи.
2. Запусти `python tools/work_plan.py validate`, затем `python tools/work_plan.py next`. Задача с незавершёнными зависимостями недоступна.
3. Не переписывай GDD ради удобства реализации. Не меняй общие контракты без отдельного согласования.
4. Работай в `task/<ID>-<slug>`; не пушь напрямую в main. Не затрагивай чужие зоны файлов.
5. Применяй только целочисленную арифметику для денег и ресурсов. Никакой клиентской авторитетной экономики.
6. Тесты обязательны. Зелёный CI является минимальным требованием, не заменяет проверку инвариантов.
7. Не хранить ключи, токены, реальные пароли и подписи APK в репозитории.
8. Никаких операций на VPS без отдельного явного разрешения. Не удалять существующие данные.
9. Статус `done` допустим только после подтверждённого слияния PR в main; в записи обязательны PR и merge SHA.
10. При смене исполнителя оставь точный отчёт: ID, ветка, PR, SHA, тесты, блокеры, что делать дальше.
11. Дорожная карта только генерируется из `tasks/tasks.json`. Не редактируй `docs/ROADMAP.md` вручную.
12. Если уже есть открытый PR по задаче, продолжай его, а не начинай дублирующую реализацию.
